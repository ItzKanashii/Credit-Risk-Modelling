# Credit Risk Modelling Using Logistic Regression

This project estimates the probability of serious delinquency within two years using the supplied cs-training.csv borrower dataset. The target is SeriousDlqin2yrs. It models Probability of Default (PD); it does not estimate Expected Loss, Loss Given Default (LGD), or Exposure at Default (EAD).

## Project stages

1. **Data understanding** — inspect the raw data, target prevalence, missing values, duplicate records, and unusual values.
2. **Cleaning and EDA** — apply the documented cleaning rules, save the cleaned dataset, and explore distributions and default rates.
3. **Risk analysis and feature engineering** — compare observed default rates across borrower groups and create total-delinquency and log-income features.
4. **Logistic regression PD model** — fit an interpretable statsmodels logistic regression using a stratified 70/30 split. Scaling is learned on training data only.
5. **Model validation and segmentation** — evaluate the reserved holdout, run stratified cross-validation within training data, assess calibration, and report risk deciles.

The group default rates and fitted coefficients describe associations; they do not establish causation.

## Setup

The project environment was run with Python 3.12.

    python -m venv .venv
    source .venv/bin/activate
    python -m pip install -r requirements.txt
    python -m ipykernel install --user --name credit-risk-modelling --display-name "Python (Credit Risk Modelling)"

On Windows, activate the environment with .venv\Scripts\Activate.ps1. From the project root, start Jupyter in the notebooks folder so the fixed relative paths resolve correctly:

    cd notebooks
    jupyter lab

Open the notebooks in order and select the Python (Credit Risk Modelling) kernel.

## Current validation results

On the reproducible held-out 30% partition, the current model has ROC-AUC **0.653**, Gini **0.306**, KS **0.233**, and Brier score **0.0616** compared with **0.0630** for a constant prediction using the training default rate. Five-fold stratified cross-validation on the training partition gives mean ROC-AUC **0.650** with fold standard deviation **0.008**.

Observed default rates increase from **2.40%** in the lowest predicted-risk decile to **13.69%** in the highest, with small non-monotonic steps. The results indicate modest discrimination and some group-level calibration error; they should not be treated as evidence of temporal stability or population-wide performance.

## Reproducibility and scope

The train/test split uses random seed 42. The saved model package contains fitted coefficients and training-only scaling values. Cross-validation refits both scaling and logistic regression within each fold. The holdout is not used to fit or select the model.

This is an educational, dataset-specific analysis, not a production credit decision system or a complete regulatory scorecard.
